# landing-keepsake

Лендінг для дизайн-агенції Keepsake за макетом з Figma.

**Демо:** https://eduard-korposh.github.io/landing-keepsake/

## Технології

- HTML, CSS
- Flexbox, Grid
- CSS-змінні, медіа-запити
- Шрифти з Google Fonts (Oswald, Open Sans, Dancing Script)

## Що зроблено

- Адаптив під телефон, планшет і комп'ютер (mobile first, брейкпоінти 768px і 1280px)
- Кольори, шрифти й відступи винесені в змінні
- Мобільне меню на popover
- Фільтр робіт по категоріях через radio-кнопки
- Ховер на картках робіт, працює і з клавіатури
- Форма підписки з перевіркою email, станом помилки та повідомленням про успіх
- Картинки у webp, іконки в svg
